- 対象: 「やるUX」無料パート（20法則の内容＋インタラクティブ・デモ）
- 立場: 第三者のUX担当エージェントによる客観監修
- 日付: 2026-05-31
- 状態: **レビューのみ（コードは未変更）**。本レポートを確認後に、採否を選んで修正に進みます。

## 1. 総評

完成度は高い。「①一言定義 ②解説 ③触れるデモ ④実践Tips ＋『この体験から分かること』」という**型が全法則で一貫**し、モバイル（375px）でも崩れず片手で操作できる。ダークパターンを避け、推定値には「（イメージ）」「簡易」と**正直な注記**がある点も好印象。`aria-live`・`focus-visible`・`prefers-reduced-motion`（グローバル）・44px以上のタップ標的など、アクセシビリティの土台も押さえている。計測系の純関数にテストがあるのも良い。

一方で、**第三者として気になる点**は主に次の4種類に集約される。

1. **時間制限デモの配慮**（延長・一時停止がない／表示が速い）
2. **1回計測デモの偶然性**（比較が運で逆転しうる）
3. **デモの主張と実装の不一致／説得力**（特に共通領域・プレグナンツ）
4. **細部の一貫性・アクセシビリティの詰め**（文言ゆれ・色依存・トップの長さ）

いずれも「壊れている（重大）」ものはなく、**中〜低**の改善提案である。

### 監修の観点
法則の正確さ / デモの説得力（本当に体感できるか）/ 学習効果 / アクセシビリティ（WCAG目安）/ 自己一貫性（アプリ自身が法則を守れているか）/ モバイル / 文言。

### 重大度の凡例
- **高**: 事実誤認・機能不全。早めに直したい。
- **中**: 学習効果や信頼性を損なう。直すと体験が目に見えて良くなる。
- **低**: 磨き込み・好み・細部の一貫性。

## 2. 横断的な所見（プロダクト全体）

| ID | 重大度 | 観点 | 所見 | 推奨 |
|----|--------|------|------|------|
| C1 | 中 | a11y/学習 | フラッシュ系（05ミラー/06系列位置/07フォン・レストルフ）に**表示時間の延長・一時停止がない**。WCAG 2.2.1（Timing Adjustable）の趣旨に外れ、読むのが速くない人には体感前に消える。 | 「もう一度見る」を結果前にも置く／表示時間を選べる（標準・ゆっくり）／開始はユーザー操作起点（多くは対応済み）。 |
| C2 | 中 | 説得力 | **1回計測の比較デモ**（09ヒック/13フィッツ/15ヤコブ）は、たまたま逆の結果が出ると法則と矛盾して見える。 | 数回の平均を取る、または「1回の差・個人差は出ます」と明示。 |
| C3 | 中 | 正確さ | 03共通領域のキャプション「**点を動かさず**枠で囲むだけで」が実装と不一致（枠化で実際にはドットが2グループに分かれて移動する）。 | 位置を固定して“背景だけ”敷く実装にする、または文言を修正。 |
| C4 | 低 | 一貫性 | リセット系の文言ゆれ（「もう一度」「もう一度ためす」「もう一度投票する」「選び直す」が混在）。 | 1〜2種類に統一（例: 操作系＝「もう一度」、結果系＝「もう一度ためす」）。 |
| C5 | 中 | 情報設計 | トップが縦に非常に長い（無料20＋有料14＝**34枚**）。カテゴリ分けは良いが、目的のカテゴリまで遠い（自分でヒックの法則に当たっている）。 | 先頭にカテゴリのアンカー（ジャンプ）リンク、または有料パックを初期折りたたみ／別ページ化。 |
| C6 | 低 | a11y | `requestAnimationFrame`で動かすアニメ（19ピーク・エンド、単純接触のフラッシュ）は**グローバルのreduced-motionが効かない**（CSSトランジションのみ無効化される）。 | `matchMedia('(prefers-reduced-motion)')`を見て簡略表示にする。 |
| C7 | 低 | コントラスト | `--text-faint`（#8c95a3）や、ソフト背景上のアクセント文字の**コントラスト比（AA 4.5:1）**が未検証。小さい文字で割れている可能性。 | 主要テキストの実測（自動チェック）と微調整。 |
| C8 | 低 | 自己一貫性 | 07フォン・レストルフの強調は「色＋わずかな拡大＋影」。法則自身のTip「**色だけに頼らない**」と矛盾しないよう、拡大・形の差をもう少し強めると盤石。 | 標的の差を色以外でも明確に（サイズ大きめ・形変更など）。 |

## 3. 法則別の所見（無料20）

特記がある法則のみ記載。記載のないものは「型どおりで良好」。

| # | 法則 | 重大度 | 所見と推奨 |
|---|------|--------|-----------|
| 01 | 近接 | 低 | 「近接なし」でも“ラベル→値”の順序が保たれ、近接以外の手掛かりが残る。2列で対比させると差がより鮮明になる。 |
| 02 | 類似 | 低 | グリッド（色/形）と偽リンクの**2題材が同居**し焦点が分散。偽リンクは強力なので主役級に昇格しても良い。偽リンクは`role="link"`だが遷移しないため、SR利用者にごく軽い違和感（学習デモとしては許容）。 |
| 03 | 共通領域 | 中 | **C3**参照（キャプションと実装の不一致）。「位置は同じ／枠だけで分かれる」が共通領域の核なので、ここは是非とも位置固定で見せたい。 |
| 04 | プレグナンツ | 中 | 回答後の「複雑：バラバラの断片?」図が“色違いの重なった円”に見え、**「断片」感が弱い**。各重なり領域に番号を振る／本当に分解した図にすると、「単純に見るほう」を選んだ意味が際立つ。また選択肢2つがどちらでも同じ結末なので、選択の意味が薄い。 |
| 05 | ミラー | 中 | **C1**。10桁／3.8秒はやや速い人も。チャンク版（区切り表示）は良い。表示時間の選択肢があると学習効果が上がる。 |
| 06 | 系列位置 | 中 | **C1＋C2**。9語／3.2秒は速く、1試行・認識式（ダミー混在）で**結果のばらつきが大きい**。中央を当てた人にも「両端が記憶に残る」と断定する文言は個人結果と乖離しうる。表示を遅く＋「一般に」を明示。 |
| 07 | フォン・レストルフ | 低 | **C8**。デモ自体は良好。 |
| 08 | ツァイガルニク | 低 | 体感よりやや説明寄り。未完了の「むずむず」をもう一歩演出する余地。まとめ文の`<br>`手動改行は画面幅で不自然になりうる。 |
| 09 | ヒック | 中 | **C2**。30択でスクロールが要るのは法則を補強する一方、探索以外の時間も混ざる（許容範囲）。 |
| 10 | 選択的注意 | 低 | 良い。対象のグレー帯を直接タップでも完了でき“ワナ”を回避できる。意図どおりだが、「購入を押させて気づかせる」狙いを強めるなら、対象帯タップは「確認しただけ」に留める手もある。 |
| 11 | 目標勾配 | 低 | 良い。投票の集計表示がなく、18美的・社会的証明（集計あり）と非一貫。 |
| 12 | パーキンソン | 低 | 実測でなく図解（used＝allotted固定）。概念デモとして妥当だが「自分の行動」を測る体験ではない点は割り切り。 |
| 13 | フィッツ | 低 | 小ターゲット40pxは“難しさ”を見せる**意図的演出**（アプリ標準の44pxとは別物）と一言添えると誤解が減る。**C2**も該当。 |
| 15 | ヤコブ | 低 | **C2**。奇抜版の本物CTAは約32px（意図的に探しにくく）。 |
| 16 | ポステル | 低 | `formatJpPhone`は簡易（市外局番の桁可変に未対応で一部の固定電話は区切りが不自然になりうる）。「簡易整形」明記済みで許容。 |
| 18 | 美的 | 低 | 「機能・情報は同一」と言いつつ、整った側は☀️アイコン等で**情報量がわずかに多い**。効果を厳密に見せるなら情報は完全一致に。 |
| 19 | ピーク・エンド | 低 | A・B両方で計約8秒待つため離脱の懸念。**C6**（reduced-motion）も該当。 |

良好（特記なし）: 14ドハティ / 17テスラー / 20パレート、ほか上記で触れていない項目。

## 4. 推奨対応リスト（優先度順）

> どれを採用するかはレポート確認後にご指示ください。番号順がおすすめ着手順です。

1. **C3 / 03共通領域**：位置固定（背景だけ敷く）か文言修正。事実整合・すぐ直せる・効果大。
2. **C1 / 05・06**：表示時間を延ばす or 「もう一度見る」追加。06は「一般に」を明示。
3. **C4**：リセット文言の統一（全デモ横断・軽作業）。
4. **C2 / 09・13・15**：「1回・個人差は出ます」の注記、または数回平均。
5. **C5**：トップの回遊性（カテゴリ・アンカー or 有料パック折りたたみ）。
6. **04プレグナンツ**：「断片」図を分かりやすく作り直す。
7. **C8 / 07**、**C6**、**C7**：アクセシビリティ・自己一貫性の微調整。

### すぐ効く小修正（Quick Wins）
- C3（文言1行）、C4（文言統一）、13/15の「意図的演出」「個人差注記」一文追加。

## 5. 評価できる点（維持したい強み）

- 全法則で一貫した「型」と「この体験から分かること」。
- モバイル前提（44px・片手・レスポンシブ）。
- ダークパターン回避、推定値の正直な注記（「イメージ」「簡易」）。
- a11yの土台（`aria-live` / `focus-visible` / グローバル`reduced-motion` / 相対パス＋HashRouter）。
- 計測ロジックの純関数にテスト。
