# Learn UX — UXの法則を“触って”学ぶ

UXデザインの主要な心理法則を、**読むのではなく操作して体感する**ためのインタラクティブ学習アプリです。各法則に「触ると一瞬で腑に落ちる」ミニ実験を1つずつ用意しています。本を読まなくても、遊んでいるうちにUXの法則が体に入ることを目指しています。

> このアプリ自身が、ここで扱う法則（フィッツ／ヒック／ドハティ／美的ユーザビリティ効果 など）に従って作られています。「UXの法則を教えるアプリは、それ自体が手本になっているべき」という考えからです。

## 何のアプリか

- 10個のUX法則を、それぞれ次の4点セットで学べます。
  1. **一言定義** — 法則を1文で
  2. **短い解説** — 自分の言葉での3〜4文
  3. **インタラクティブ・デモ** — 実際に触って体感する実験（各法則必須）
  4. **実践Tips** — 「だから設計ではこうする」2〜3個
- 各デモには「**この体験から分かること**」という一言まとめが付きます。
- スマホ（幅375px）でも崩れず、片手で操作できるレスポンシブ設計です。

## ローカルでの起動方法

前提: Node.js 20+ / npm

```bash
# 1. 依存をインストール
npm install

# 2. 開発サーバを起動（http://localhost:5173 が開きます）
npm run dev

# 3. 本番ビルド（型チェック込み）
npm run build

# 4. ビルド成果物をプレビュー
npm run preview

# 5. ユニットテスト（計測ロジックの純関数など）
npm test
```

## 自分のサイト（ホームページ）に載せる

`npm run build` を実行すると `dist` フォルダができます。**この `dist` フォルダの中身（`index.html` と `assets` フォルダ）を、あなたのWebサーバー（ホームページ）の好きな場所にアップロードするだけ**で公開できます。

Vite の `base` を相対パスにし、ルーティングをハッシュ方式（HashRouter）にしているため、サイトのどのフォルダ（例: `https://example.com/learn-ux/`）に置いても動作し、ページを再読み込みしても404になりません。サーバー側の特別な設定は不要です。

### 1ファイルだけで配布・オフライン閲覧したいとき

```bash
npm run build:standalone
```

JS/CSSをすべて埋め込んだ単一の `dist-standalone/index.html` が生成されます。このファイルは**ダブルクリックするだけ**でブラウザで開け（インターネット接続不要）、メール添付やUSBでの受け渡しにも向きます。

## 技術スタック

- **React 19 + TypeScript + Vite** — 高速な開発・ビルド
- **CSS Modules + CSSカスタムプロパティ** — 軽量・依存少なめでデザインを一貫
- **react-router-dom（HashRouter）** — トップ⇄各法則の行き来。サブパス配信でも壊れないハッシュ方式
- **状態管理** — 標準の `useState` のみ（重いライブラリは入れない）
- **Vitest + Testing Library** — 計測ユーティリティ（純関数）のテスト

```
src/
├── components/   共通レイアウト・カード・法則ページの「型」
├── pages/        トップ / 各法則ページ
├── laws/         各法則のインタラクティブ・デモ
├── data/laws.tsx 10法則のメタデータ（定義・解説・Tips）
└── utils/        計測まわりの純関数（テスト付き）
```

## 扱う10法則

| #  | 法則 | 一言 |
|----|------|------|
| 01 | ヤコブの法則 (Jakob's Law) | ユーザーは他サイトでの経験を期待する |
| 02 | フィッツの法則 (Fitts's Law) | 標的は大きく近いほど速く押せる |
| 03 | ミラーの法則 (Miller's Law) | 一度に覚えられるのは 7±2 個 |
| 04 | ヒックの法則 (Hick's Law) | 選択肢が多いほど決定は遅れる |
| 05 | ポステルの法則 (Postel's Law) | 入力に寛容、内部に厳格 |
| 06 | ピーク・エンドの法則 (Peak–End Rule) | 印象はピークと終わりで決まる |
| 07 | 美的ユーザビリティ効果 (Aesthetic–Usability Effect) | 美しいUIは使いやすく感じる |
| 08 | フォン・レストルフ効果 (Von Restorff Effect) | 際立つものが記憶に残る |
| 09 | テスラーの法則 (Tesler's Law) | 複雑さは消えず誰かが引き受ける |
| 10 | ドハティのしきい値 (Doherty Threshold) | 0.4秒以内の応答で没頭できる |

## 出典・クレジット

法則の名前と概念は学術的な共有知ですが、本アプリの**解説文・Tips・一言定義はすべて独自に書き起こしたもの**で、書籍やWebサイトの文章を転記してはいません。

法則の体系的な整理にあたっては、以下を参考にしています。

> **Jon Yablonski “Laws of UX”**（[lawsofux.com](https://lawsofux.com/) / オライリー・ジャパン 邦訳『Laws of UX 使いやすいプロダクトとサービスをデザインするための心理学』）

各法則の元となった研究（Fitts 1954, Miller 1956, Hick 1952 ほか）は、それぞれの提唱者に帰属します。
