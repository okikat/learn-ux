# やるUX — 読むより、やる。

UXデザインの主要な心理法則を、**さわって覚える**ためのインタラクティブ学習アプリです。各法則に「触ると一瞬で腑に落ちる」ミニ実験を1つずつ用意しています。本を読まなくても、遊んでいるうちにUXの法則が体に入ることを目指しています。**20の法則すべて無料**です。

> このアプリ自身が、ここで扱う法則（フィッツ／ヒック／ドハティ／美的ユーザビリティ効果 など）に従って作られています。「UXの法則を教えるアプリは、それ自体が手本になっているべき」という考えからです。

## 何のアプリか

- 20個のUX法則を5カテゴリに分けて収録。それぞれ次の4点セットで学べます。
  1. **一言定義** — 法則を1文で
  2. **短い解説** — 自分の言葉での3〜4文
  3. **インタラクティブ・デモ** — 実際に触って体感する実験（各法則必須）
  4. **実践Tips** — 「だから設計ではこうする」2〜3個
- 各デモには「**この体験から分かること**」という一言まとめが付きます。
- スマホ（幅375px）でも崩れず、片手で操作できるレスポンシブ設計です。
- **20の法則すべて無料**で公開しています。

## ローカルでの起動方法

前提: Node.js 20+ / npm

```bash
# 1. 依存をインストール
npm install

# 2. 開発サーバを起動（http://localhost:5173 が開きます）
npm run dev

# 3. 本番ビルド（型チェック込み）
npm run build

# 4. ビルド成果物をプレビュー
npm run preview

# 5. ユニットテスト（計測ロジックの純関数など）
npm test
```

## 自分のサイト（ホームページ）に載せる

`npm run build` を実行すると `dist` フォルダができます。**この `dist` フォルダの中身（`index.html` と `assets` フォルダ）を、あなたのWebサーバー（ホームページ）の好きな場所にアップロードするだけ**で公開できます。

Vite の `base` を相対パスにし、ルーティングをハッシュ方式（HashRouter）にしているため、サイトのどのフォルダ（例: `https://example.com/learn-ux/`）に置いても動作し、ページを再読み込みしても404になりません。サーバー側の特別な設定は不要です。

### 1ファイルだけで配布・オフライン閲覧したいとき

```bash
npm run build:standalone
```

JS/CSSをすべて埋め込んだ単一の `dist-standalone/index.html` が生成されます。このファイルは**ダブルクリックするだけ**でブラウザで開け（インターネット接続不要）、メール添付やUSBでの受け渡しにも向きます。

## 技術スタック

- **React 19 + TypeScript + Vite** — 高速な開発・ビルド
- **CSS Modules + CSSカスタムプロパティ** — 軽量・依存少なめでデザインを一貫
- **react-router-dom（HashRouter）** — トップ⇄各法則の行き来。サブパス配信でも壊れないハッシュ方式
- **状態管理** — 標準の `useState` のみ（重いライブラリは入れない）
- **Vitest + Testing Library** — 計測ユーティリティ（純関数）のテスト

```
src/
├── components/   共通レイアウト・カード・法則ページの「型」
├── pages/        トップ / 各法則ページ
├── laws/         各法則のインタラクティブ・デモ
├── data/laws.tsx 20法則のメタデータ（定義・解説・Tips・カテゴリ）
└── utils/        計測まわりの純関数（テスト付き）
```
